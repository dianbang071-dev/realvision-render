Sun & Sky / Solar Position

Versi 1.4 memakai procedural daylight sky dan directional sunlight pada CPU reference renderer. Azimuth/elevation default sementara 135°/35°.

Azimuth dihitung dari +Y ke +X; elevation dari horizon. Gunakan kalkulasi posisi matahari berdasarkan tanggal, jam lokal, koordinat, dan UTC offset.

Koordinat harus diisi sendiri. Contoh koordinat hanya panduan, bukan lokasi otomatis.

Render Preview
Siap. Pilih executable engine hasil build Windows.

Render utama versi ini masih CPU reference renderer dengan BRDF PBR GGX eksperimental untuk pencahayaan IES. HDRI .hdr, IES TILT=NONE, dan denoising CPU tersedia. Tekstur BMP (24/32-bit tanpa kompresi) dan PPM (P3/P6, max value 255) tersedia pada CPU; PNG/JPG (jika libpng/libjpeg tersedia saat build), back-face texture, GPU ray tracing belum aktif; pemeriksaan RT hanya membuat logical device dan membaca properti perangkat; tombol diagnostik hanya memeriksa driver, ekstensi, dan pembuatan logical device Vulkan, bukan menjalankan render GPU. Sun & Sky prosedural dan directional sunlight tersedia pada CPU renderer. Output menggunakan ACES-like tone mapping, exposure, anti-alias jitter, dan bloom CPU. Transmisi/refraction dielektrik masih eksperimental pada CPU. Emissive area lighting tersedia pada CPU reference renderer sebagai direct-light sampling eksperimental. Ekspor membawa mesh triangulasi, UV front-face, material, kamera, dan tekstur BMP yang berhasil diekspor oleh SketchUp. Tekstur yang gagal diekspor memakai warna dasar material.
